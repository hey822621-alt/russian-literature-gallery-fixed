# 文学画廊 · 弧形轮播与柔雾预览

仅为本地预览，正式网站没有部署修改。

## 修改
- 保留五位作家肖像、专属整站配色，以及此前三幅重复插画的修复。
- 作品展厅改为相框沿三维弧线转动，中央画框正面展示，侧边画框有透视纵深；支持按钮、方向键、触摸滑动、缩略图、自动播放与暂停。只有一幅作品时保持静止。
- 首页玻璃面板覆盖整幅主视觉，使用低饱和弥散光、细边框和奶白色大标题。
- 中文内置官方思源黑体可变字体，字间距收紧；俄语配置 Franie 优先，但尚无 Franie 文件，当前使用后备无衬线字体，不能视为 Franie 已交付。
- 修正快速切换时旧标题延迟覆盖，以及浏览作品时作者自动切换的问题。

## 查看
双击 dist/index.html 可离线浏览。开发预览：npm run build，再 npm run preview，打开 http://localhost:4173。

## 来源与核对
2026-11-03 已经读取正式站 HTML。本地原始正式版构建与正式站页面逐字节一致，确认基线。该基线是原生 HTML/CSS/JavaScript，而非早期 Astro 压缩包。
共52张引用图片验证可解码、文件哈希无重复；44幅其他作品插画与正式版逐字节一致，仅三幅指定重复图被替换。
肖像和新情节画为内置 ImageGen 生成的艺术重绘，非历史原画。
